# 키보드 웹뷰 리사이즈 데모

iOS에서 입력창을 눌렀을 때 Capacitor 키보드 플러그인이 웹뷰를 언제 줄이는지를, 플러그인 원본과 패치 후 두 화면을 나란히 놓고 같은 순간에 재생해 비교하는 데모다.

- 글: [웹 앱을 Capacitor로 감싸고 나서 생긴 결함 고치기](/posts/capacitor-app-bugs/)
- 데모: `/demos/keyboard-resize/`

## 재현하는 현상

두 화면의 입력창을 동시에 누르면 키보드가 0.25초 동안 올라온다. 플러그인 원본은 키보드 애니메이션 시간에 0.2초를 더 기다린 0.45초에 웹뷰를 줄이고, 그동안 입력창이 키보드에 가려진다. 패치 후는 키보드가 뜨기 시작할 때 바로 웹뷰를 줄인다.

## 화면

봐야 할 것은 입력창 하나다. 빨강과 초록은 입력창에만 쓰고, 말풍선과 키보드는 글자나 자판 없이 회색 덩어리로 둔다.

- 위 문장: 멈춰 있을 때 그 순간에 일어나는 일(대기, 키보드가 올라오는 중, 원본만 가려진 동안, 원본도 줄인 뒤). 재생하는 동안에는 바뀌지 않는다.
- 4배 느리게 재생: 0.6초를 2.4초 동안 재생한다. 움직임 줄이기 설정이면 재생 대신 0.35초 순간을 보여준다.
- 두 화면: 플러그인 원본, 패치 후. 회색 바탕이 웹뷰이고, 웹뷰 밖은 앱 바탕이다. 입력창이 보이면 초록 테두리, 키보드에 가려져 있으면 그 자리에 빨간 점선을 키보드 위로 비춰 보인다.
- 시간 막대: 원본에서 입력창이 가려지는 구간을 빨갛게 칠하고(범례는 막대 위 오른쪽. 손잡이가 늘 이 구간을 지나가서 막대 안에는 글자를 두지 않는다) 0.25초(키보드 다 올라옴)와 0.45초(원본 웹뷰 줄임)에 눈금을 둔다. 막대를 누르거나 끌면 그 순간을 보고, 포커스한 뒤 화살표 키로 0.01초씩, Home과 End로 처음과 끝으로 옮긴다.

## 옮긴 코드와 뺀 것

`keyboard.ts`의 `resizeDelay`는 `@capacitor/keyboard` 8.0.1 `ios/Sources/KeyboardPlugin/Keyboard.m`의 `onKeyboardWillShow`에서 웹뷰를 줄이기까지 기다리는 시간만 옮겼다. 원본은 `UIKeyboardAnimationDurationUserInfoKey` 값에 0.2초를 더하고, 패치 후는 0이다.

뺀 것은 키보드가 내려갈 때 처리, Stage Manager 보정(`stageManagerOffset`), `performWithoutAnimation`, 실제 웹뷰 frame 계산이다. 데모에서는 웹뷰 높이를 한 번에 바꾼다.

## 알아둘 점

- 키보드 애니메이션 시간 0.25초와 키보드 높이, 화면 높이는 예시 값이다(`samples.ts`). 0.2초만 플러그인 코드 그대로다.
- 키보드가 올라오는 곡선은 ease-out으로 흉내 낸 것이고 iOS 곡선과 같지 않다.
- 원본에서 웹뷰를 줄이기 전까지 입력창이 키보드에 가려지는 모습은 키보드가 웹뷰 위에 겹쳐 뜬다는 전제로 그렸다.
